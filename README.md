# Autopilot Devcontainer

## 概要

このリポジトリは、アイデアを検証するための開発環境です。各プロジェクトで異なるアイデアの開発環境を作成し、Coding Agent によって実装・検証を行います。

## 基本方針

- ディレクトリ単位でのプロジェクト管理: 各プロジェクトは独立したディレクトリで開発
- 自己完結性: 各プロジェクトは他に依存せず、独立して動作
- 将来の分離可能性: プロジェクトが成熟した際に新しいリポジトリに分離可能
- Coding Agent による実装: AI アシスタントを活用した効率的な開発

## ディレクトリ構造

```
autopilot-sandbox/
├── README.md             # このファイル
├── CLAUDE.md             # Coding Agent向けの詳細な指示
├── GEMINI.md             # Coding Agent向けの詳細な指示
└── projects/             # プロジェクト群
```

## 新しいプロジェクトの始め方

### 1. プロジェクトの概要を決める

- 何を作りたいか
- どの技術スタックを使うか
- どのような機能が必要か

### 2. Coding Agent に依頼する

```
@claude
新しいプロジェクト「[プロジェクト名]」を実装してください。
- 技術スタック: [使用技術]
- 機能: [必要な機能の説明]
- 目標: [達成したい目標]
```

### 3. 実装確認

- 基本機能が動作することを確認
- テストが通ることを確認
- ドキュメントが整備されていることを確認

## プロジェクトの成熟度レベル

### レベル 1: 実験段階

- 基本的なプロトタイプ
- 主要機能の検証
- 簡単なテスト

### レベル 2: 開発段階

- 機能の拡張
- 包括的なテスト
- ドキュメントの充実

### レベル 3: 成熟段階

- 本格的な実装
- CI/CD 設定
- 独立リポジトリ準備完了

## 貢献方法

1. Issues でアイデアを提案
2. Coding Agent に実装を依頼
3. 実装結果をレビュー
4. 必要に応じて改善を要求

## 注意事項

- 各プロジェクトは独立して動作する必要があります
- 他のプロジェクトへの依存は避けてください
- 将来的に独立したリポジトリに分離することを想定して開発してください

詳細な開発ガイドラインは [guideline.md](.prompts/guideline.md) を参照してください。
